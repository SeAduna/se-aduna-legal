Support — Se Adună

Last updated: 26 September 2026 · applies to Se Adună version 1.1.4

If you have a question about the “Se Adună” app or run into a problem, you can write to us at any time — we reply directly by e-mail.

Contact: OADsupport@gmail.com

Technical problems

If the app crashes, shows wrong data or behaves unexpectedly, write to us at the address above. If you can, please mention your phone model and operating system version (iOS/Android) — it helps us reproduce the problem faster.

Questions about using the app

For any question about how the cost calculation, the budget, receipts, Impulse Pause, Micro-Journal, Real Work or the Memory Graveyard work, write to the contact address. The app has no account and your data (including photos) stays stored on your phone, so we cannot access or recover it remotely — but we can help with any question about the features. Details about the camera, backups and deletion are in the Privacy Policy.
