# Pagini legale — Se Adună

Acest folder conține paginile HTML statice ale documentelor legale ale aplicației **Se Adună**, publicate la https://seaduna.github.io/se-aduna-legal/.

Limba de referință este româna. Versiunile în engleză (`-en`) și spaniolă (`-es`) sunt echivalente ca sens cu cele în română.

## Fișiere

| Document | Română | English | Español |
|---|---|---|---|
| Politica de confidențialitate | `privacy-policy.html` | `privacy-policy-en.html` | `privacy-policy-es.html` |
| Termeni și condiții | `terms.html` | `terms-en.html` | `terms-es.html` |
| Declarație de exonerare financiară | `financial-disclaimer.html` | `financial-disclaimer-en.html` | `financial-disclaimer-es.html` |
| Suport | `support.html` | `support-en.html` | `support-es.html` |

`index.html` — pagina principală, cu linkuri către toate documentele în cele trei limbi.

## Sursă

Sursa de referință pentru versiunea în limba română a documentelor juridice este fișierul Markdown corespunzător din `legal/` (`POLITICA_DE_CONFIDENTIALITATE.md`, `TERMENI_SI_CONDITII.md`, `DECLARATIE_EXONERARE_FINANCIARA.md`). Dacă se modifică conținutul juridic, se actualizează mai întâi versiunea în română, apoi echivalentele în engleză și spaniolă.

Acest folder nu are legătură cu `webapp/`.
