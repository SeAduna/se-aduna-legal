# Pagini legale — Se Adună

Acest folder conține paginile HTML statice ale documentelor legale ale aplicației **Se Adună**, publicate la https://seaduna.github.io/se-aduna-legal/.

## Fișiere

- `index.html` — pagină cu linkuri către documentele de mai jos
- `privacy-policy.html` — Politica de confidențialitate
- `terms.html` — Termeni și condiții de utilizare
- `financial-disclaimer.html` — Declarație de exonerare financiară
- `support.html` — Pagină de suport / contact

## Sursă

Conținutul acestor pagini este derivat din documentele Markdown din `legal/` (`POLITICA_DE_CONFIDENTIALITATE.md`, `TERMENI_SI_CONDITII.md`, `DECLARATIE_EXONERARE_FINANCIARA.md`). Dacă se modifică conținutul juridic, sursa de referință rămâne fișierul Markdown corespunzător din `legal/`.

Acest folder nu are legătură cu `webapp/`.
